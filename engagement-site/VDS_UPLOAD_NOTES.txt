2) QR LINK DEĞİŞTİRME
---------------------
script.js içinde şu satırı değiştir:

const INVITE_URL = 'https://engagement.safuak.xyz';

Örnek:
const INVITE_URL = 'https://nisan.safuak.xyz';

QR görseli şu an placeholder link için üretildi:
https://engagement.safuak.xyz

Domain kesinleşince QR görselini yeniden üretmek daha doğru olur.

3) WINDOWS VDS BASİT CANLIYA ALMA
---------------------------------
En kolay başlangıç:
- Windows Server 2022
- Python 3.12/3.13
- Flask + Waitress
- IIS reverse proxy veya direkt Waitress

Komutlar:
python -m venv .venv
.venv\Scripts\activate
pip install flask waitress
waitress-serve --host=127.0.0.1 --port=8080 app:app

IIS ile public 80/443 -> 127.0.0.1:8080 reverse proxy yapılabilir.

4) UPLOAD ENDPOINT
------------------
Frontend hazırdır.
script.js içinde:

const REAL_UPLOAD_ENABLED = false;
const UPLOAD_ENDPOINT = '/api/memories/upload';

Backend hazır olunca:
const REAL_UPLOAD_ENABLED = true;

Upload formu şu alanları gönderir:
- guestName
- guestEmail
- guestNote
- memories[]

5) GÜVENLİ UPLOAD İÇİN ÖNERİLEN KURALLAR
----------------------------------------
- Maks fotoğraf: 20 MB
- Maks video: 500 MB
- Kabul edilen uzantılar: jpg, jpeg, png, webp, heic, mp4, mov, webm
- Dosya adı asla direkt kullanılmamalı, UUID ile kaydedilmeli
- Upload klasöründe execute izni olmamalı
- Microsoft Defender ile dosya taraması yapılmalı
- Misafirlerin yüklediği dosyalar önce moderation / pending durumuna alınmalı
- Admin onaylamadan public galeride görünmemeli

Önerilen klasör:
D:\engagement-site\uploads\
  incoming\
  staging\
  approved\
  rejected\
